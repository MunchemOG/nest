# Pet Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pure-Swift brain of pet mode in NestKit. Given a snapshot of the Mac, it decides which idle birds are out, where each one perches, what it's doing, and how it reacts to the pointer.

**Architecture:** Each tick, a `PetWorld` snapshot goes into a `PetDirector`. The director runs an `ActivityTracker` (work streak), a `PetScheduler` (mode, plus who is out) and a `PetBrain` (each bird's state machine, plus pointer reactions), and returns a `PetIntent` per bird. There's no AppKit or UI: everything is a value type with an injected clock (`world.now`) and a seeded random source, so every behaviour replays exactly in tests.

**Tech Stack:** Swift 6, Swift Testing, Foundation only. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-11-pet-mode-design.md`

**Not in this plan:** the menu bar helper, the overlay window, the Metal renderer, the sensors and the hotkey. They wait for the look hold to lift and for a menu bar helper task, and get their own plan. This plan is buildable now because it has no UI.

## Global Constraints

- Every file lives in `NestKit/Sources/NestKit/Pets/`; tests live in `NestKit/Tests/NestKitTests/`.
- Every public thing gets a one-line `///` doc comment. One type per file, named for the type.
- No AppKit, SwiftUI or CoreGraphics in `Pets/`. Points are `PetPoint`; time is `Date` plus `TimeInterval` seconds.
- Behaviour numbers (minutes, radii in points, dwell times) live only in `PetSettings` and `BirdQuirks`, as the spec requires ("All numbers live in `PetSettings`"). Drawing values (sizes, mote counts, flight speed) are not in this plan; they belong in tokens in the renderer plan.
- The go-home time is `NestMotion.slow` (420 ms), read from the token and never retyped.
- Only birds whose `BirdState.status(at: world.now)` is `.resting` or `.asleep` may ever be out.
- Mode precedence: hidden, then lively, then breakBuddy, then visitor.
- Tests use no network and no real files; randomness always comes from `PetRandom(seed:)`.
- Per Mithun's standing rule, the executor does not run git writes. Each "Commit" step means handing Mithun the commands shown. Commit messages are `<task id>: <what changed>`.
- Run one suite with `swift test --package-path NestKit --filter <SuiteName>`. Run the whole suite with `xcodebuild test -scheme NestApp -destination 'platform=macOS'` and paste the result line.

## Review Focus

1. **Mac sleeps and wakes:** `now` jumps hours ahead. Expect no burst of visits and a work streak back at zero. Owned by PB-01 (`aClockJumpResetsTheStreak`) and PB-03 (`aClockJumpDoesNotReleaseABacklogOfVisits`).
2. **Two birds pick the same spot:** the birds stack on top of each other. Expect no two out birds within `perchSpacing` of each other. Owned by PB-04 (`twoBirdsNeverShareAPerch`).
3. **No perches at all:** the Dock auto-hides, there's no Accessibility, and no windows are open. Expect the birds to stay home, with nothing crashing and no bird stuck in `flyingOut`. Owned by PB-04 (`withNoPerchesBirdsStayHome`).
4. **The front app changes mid-visit:** Xcode, then Safari. Expect the current visitor to finish its visit, not swap birds on every app switch. Owned by PB-03 (`switchingAppsMidVisitKeepsTheVisitor`).
5. **A bird gets work while reacting:** it's sitting on the pointer, fleeing or following. Expect busy to win and the bird to go home within 420 ms. Owned by PB-05 (`busyBeatsEveryPointerReaction`).

### Task PB-03: PetScheduler

**Files:**
- Create: `Pets/PetMode.swift`, `Pets/PetPlan.swift`, `Pets/PetScheduler.swift`
- Test: `PetSchedulerTests.swift`

**Interfaces:**
- Consumes `PetWorld`, `PetSettings` and `PetRandom` (PB-01), and `BirdQuirks.of(_:).apps` (PB-02).
- Produces:
  - `enum PetMode: Hashable, Sendable { visitor, breakBuddy, lively, hidden }`
  - `struct PetPlan: Hashable, Sendable { var mode: PetMode; var out: Set<Bird>; var favoured: Bird?; var hideCauses: Set<HideCause> }`
  - `struct PetScheduler: Sendable { init(settings: PetSettings); mutating func plan(_ world: PetWorld, streak: TimeInterval, using rng: inout some RandomNumberGenerator) -> PetPlan; static func favoured(in world: PetWorld, settings: PetSettings) -> Bird? }`

**Rules** (the order is the precedence):

1. **Hide causes** are `world.hideCauses`, plus `.meetingApp` when `frontApp` is in `settings.meetingApps`.
   - If any cause is present, the mode is `hidden` and `out` is empty.
   - Any visit or break in progress ends.
   - When hidden ends, the next visit is rescheduled to `now + random(visitGap)`.
2. **Lively:** if `secondsSinceInput >= livelyAfter`, the mode is `lively` and `out` is every idle bird.
   - On the first non-lively tick after lively, if `now >= nextVisit`, one bird that was out (the favoured one if it was out, otherwise random) stays as the visitor, with `visitEnd = now + random(visitLength)`.
3. **Break buddy:** if `streak >= breakAfter` and `now >= cooldownEnd`, it starts.
   - It picks `random(breakBirds)` idle birds, capped at the number idle.
   - It sets `breakEnd = now + breakLength` and `cooldownEnd = breakEnd + breakCooldown`.
   - While `now < breakEnd`, the mode is `breakBuddy` and `out` is those birds, still filtered to idle.
4. **Visitor:** `nextVisit` is first set on the first tick to `now + random(visitGap)`.
   - When `now >= nextVisit` and there's no visitor, it picks `favoured` if that bird is idle, otherwise a random idle bird, and sets `visitEnd = now + random(visitLength)`.
   - The visit ends when `now >= visitEnd` or the visitor stops being idle. Then `nextVisit = now + random(visitGap)`.
   - If `now - nextVisit > visitGap.upperBound` (a clock jump), it reschedules instead of releasing a visit.
5. **Favoured bird:** if `hour >= nightStartHour || hour < nightEndHour` and Owl is idle, it's Owl. Otherwise it's the idle bird whose `apps` contains `frontApp`. Otherwise nil.
6. `out` is always a subset of `world.idleBirds`.

### Task PB-04: PetBrain movement

**Files:**
- Create: `Pets/PetIntent.swift`, `Pets/PerchChoice.swift`, `Pets/PetBrain.swift`
- Test: `PetBrainMovementTests.swift`

**Interfaces:**
- Consumes `PetPlan` (PB-03), and `BirdQuirks`, `PetActivity` and `PetReaction` (PB-02).
- Produces:
  - `struct PetIntent: Hashable, Sendable { var activity: PetActivity; var reaction: PetReaction?; var target: PetPoint; var travel: TimeInterval; var shape: PetShape { activity.shape } }`
  - `enum PerchChoice { static func choose(for bird: Bird, plan: PetPlan, world: PetWorld, taken: [PetPoint], using rng: inout some RandomNumberGenerator) -> Perch? }`
  - `struct PetBrain: Sendable { init(settings: PetSettings); mutating func intents(plan: PetPlan, world: PetWorld, using rng: inout some RandomNumberGenerator) -> [Bird: PetIntent] }`. It always returns all six birds.

**Perch choice,** in order:

1. Drop any perch within `perchSpacing` of a point in `taken`.
2. If the bird is `plan.favoured` and `frontApp` is set, use perches whose `app == frontApp`, `dockIcon` before `windowTop`.
3. If the mode is `breakBuddy`, use the perch nearest `world.pointer`.
4. Otherwise, pick at random among the perches of the most-preferred `Kind` present.
5. With no candidates, return nil.

**Movement,** per bird per tick. `taken` is the perch points of birds already handled this tick, in `Bird.allCases` order.

- **Leaving:** if a bird isn't in `plan.out` and isn't home, it becomes `flyingHome` with target `homes[bird]`, then `home` once `travel` has passed. `reaction` is `quirks.homeReaction`. `travel` depends on why it left:
  - `PetSettings.goHome` if the mode is `hidden` or the bird isn't idle,
  - `livelySettle` if the previous mode was `lively`,
  - otherwise `flightTime`.
- **Coming out:** a bird in `plan.out` that is home or `flyingHome` becomes `flyingOut` to `PerchChoice`, with `travel = flightTime`. If the choice is nil, it stays `home`.
- **Arriving:** `flyingOut` becomes `perched` when `travel` has elapsed, staying `random(quirks.dwell)`.
- **Settling:** `perched` draws the next step when its dwell ends:
  - In `lively`: with p = 0.6, `looping`, or `chasing` with the target being another out bird's point; otherwise a hop to a new perch.
  - In any other mode: with p = 0.5, `quirks.habit`; otherwise a hop to a new perch, as `flyingOut` there.
  - Habit, looping and chasing each last `random(quirks.dwell)`, then the bird is `perched` again on its own perch.
- **Front app changes:** any out bird with `curiosity >= 0.9` and a perch for the new app becomes `flyingOut` to it.
- **Missing home:** a bird with no `homes` entry never comes out.

### Task PB-05: Pointer reactions

**Files:**
- Create: `Pets/PointerReaction.swift`, which holds the reaction rules as `PetBrain` extension functions.
- Modify: `Pets/PetBrain.swift`, applying the reactions after movement each tick.
- Test: `PetBrainPointerTests.swift`

**Interfaces:**
- Consumes `PetBrain` (PB-04) and `BirdQuirks` (PB-02).
- Produces no new public API. `PetBrain.intents` now includes reactions.

**Rules.** They apply only to out birds whose activity is `perched`, `preening`, `hopping`, `dozing`, `following` or `looping`. Let `d` be the distance from the pointer to the bird's current point. The brain tracks when the pointer last moved faster than `stillSpeed`. The first rule that matches wins:

1. **Busy or hidden:** the movement rules from PB-04 always win. A bird that isn't in `plan.out` gets no reaction except `homeReaction`.
2. **Rush:** if `d <= fleeDistance` and `pointerSpeed >= rushSpeed`, the bird becomes `fleeing`, with `reaction = quirks.rush` and `travel = flightTime`. It flees to a `PerchChoice` with perches within `2 × fleeDistance` of the pointer removed.
   - If `returnsAfterFleeing` is set, then after `dwell.lowerBound` it flies back to the perch it fled.
3. **Hover:** if `d <= hoverRadius` and `pointerSpeed < stillSpeed`, the bird keeps its activity and gets `reaction = quirks.hover`.
   - A bird with `approachesStillPointer` and `bravery >= 0.9` that has been still for `sitAfter` becomes `perched` with the pointer as its target and `reaction = .sitOnPointer`.
4. **Approach:** if `approachesStillPointer`, `d <= approachRadius` and the pointer has been still for `approachAfter`, the bird becomes `hopping` to the point `hoverRadius` from the pointer on the bird's side, with `reaction = .hopCloser`.
5. **Follow:** if `followsPointer`, `d <= approachRadius` and `pointerSpeed >= stillSpeed`, the bird becomes `following`, with its target `followDistance` from the pointer toward the bird.
6. **Near:** if `quirks.near` isn't nil and `d <= approachRadius`, the bird keeps its activity and gets that reaction.
